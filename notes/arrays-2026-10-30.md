# The arrays brief: an array made by its rule, and a def that makes one

**Status (2026-10-30): A built, for local and state arrays; B closed as
unneeded.** Roland wasn't sure a rule-built array was the elegant thing
(he hadn't seen it in OCaml or JS; OCaml's `Array.init n f` and JS's
`Array.from({length: n}, f)` are the same idea). What convinced him was
the state half: a rule as a state array's `init` is a field's starting
shape, u(x, 0) = f(x), which aither could not say at all. A number or
pair as `init` is the rule that ignores its index, so A widens `init` and
adds no name. B is covered without a construct (below, "B closed").

## Where it is today

A local array whose elements follow a rule is written in two lines: the
array, then `each` storing into it. The patches doing that:

| patch | arrays |
|---|---|
| `patches/lib/voice.aither` (`trombone`) | the tract's areas `a`, its reflections `r`, the nose's reflections `nr`, the gesture's spread `h` |
| `patches/didge_vowels.aither`, `didge_vowels_ref.aither` | the sections' areas `s` |
| `patches/around.aither` | the field `a` |

`r` and `nr` are the same formula, the reflection at each junction
between two sections, written twice because there is no def to name it.

## A: the initial value may be the rule

`array(n, init)` already takes a number or a pair as `init`. Let it take
a function of the index too: `array(n, i => …)` is the array whose
element `i` is the rule at `i`, for `i` from 0. That is `let x =
array(n)` plus `each(n, i => x[i] = …)` in one, and adds no name.

`lib/voice`, today:

```
let r = array(24)                              # r[j]: reflection between sections j - 1 and j
each(23, j => r[j + 1] = (a[j] - a[j + 1]) / (a[j] + a[j + 1]))
let nr = array(16)                             # the nose's junctions
each(15, i => nr[i + 1] = (nA[i] - nA[i + 1]) / (nA[i] + nA[i + 1]))
...
let h = array(24)
each(24, j => h[j] = max(0, 1 - abs(j - cidx)))
```

with A:

```
let r  = array(24, j => if j == 0 then 0 else (a[j - 1] - a[j]) / (a[j - 1] + a[j]))
let nr = array(16, j => if j == 0 then 0 else (nA[j - 1] - nA[j]) / (nA[j - 1] + nA[j]))
...
let h  = array(24, j => max(0, 1 - abs(j - cidx)))
```

`didge_vowels`:

```
let s = array(8)                                  # each section's area
each(8, j => s[j] = pow(1 + (wide - 1) * pow((j + 0.5) / 8, 3), 2))
```

```
let s = array(8, j => pow(1 + (wide - 1) * pow((j + 0.5) / 8, 3), 2))   # each section's area
```

`around`'s field:

```
let a = array(n, [0, 0])
each(n, m =>
  a[m] = sum(arrivals, k => heard_s[k - 1] * wound(bearing[k - 1], m))
  a[m] = rotate(a[m], -m * yaw))
```

```
let a = array(n, m => rotate(sum(arrivals, k => heard_s[k - 1] * wound(bearing[k - 1], m)), -m * yaw))
```

Where `each` stays right: `around`'s arrivals fill two arrays (`heard_s`
and `bearing`) from shared geometry in one pass, and the waveguides'
scattering stores into several arrays at once. A is for one array made
by one rule; `each` is for a step.

Edges: for a state array the rule is its starting shape, evaluated on
the sample the array is born and then left alone, as a constant `init`
is. An `every` array takes it in both its generations. The elements are what the rule returns, numbers or pairs, as with
any `init`.

## B: a def may end in an array

A def whose last expression is an array (a name bound to a local array,
`array(…)`, or a list) returns it, and the call binds where it is let:
`let r = reflections(a)`. Defs are inlined, so this is the caller's name
bound to the array the def's body made, with no copying and no runtime
array type. A call that returns an array anywhere but a `let` is an
error ("an array: bind it with let").

`lib/voice` with A and B:

```
# The reflection at each junction, between sections j - 1 and j.
def reflections(areas):
  array(len(areas), j => if j == 0 then 0 else (areas[j - 1] - areas[j]) / (areas[j - 1] + areas[j]))

let r  = reflections(a)
let nr = reflections(nA)
```

`around`'s field as defs, which spatial-2026-10-29.md wanted for the
stdlib:

```
def turned(a, angle): array(len(a), m => rotate(a[m], m * angle))
let a = turned(array(n, m => sum(arrivals, k => heard_s[k - 1] * wound(bearing[k - 1], m))), -yaw)
```

## What each costs

- **A:** the `array` call learns a third kind of `init`. The compiler
  already unrolls `each` with a compile-time count; A is that, emitted
  where the array is declared. SPEC: one paragraph under "Local arrays".
- **B:** a `let` whose value is a call to a def ending in an array binds
  the def's array to the name. The def's body is already inlined into
  the caller; what is new is passing the array's entry back out. SPEC:
  "Defs don't return arrays" becomes a paragraph saying how they do.
  Not covered: an array returned from a `def rec` (its loop has no place
  to put one), and an array into a lambda (the brief's other half; no
  patch asks for it).

## Recommendation

**A now:** it is small, adds no name, and turns every two-line array in
the patches into one line that reads as the rule. **B with it:** it
is what makes `r` and `nr` one formula, and it is the half the fields
work asked for (`turned`, `encode`). Both stay within "a program is one
sample at one place": nothing maps over arrays, no arithmetic on whole
arrays (that was V).

## Built (2026-10-30)

`array(n, i => …)` for local and state arrays: the rule unrolled once an
element, its index a compile-time number as in `each`. `lib/voice`
(four arrays), `didge_vowels`, `didge_vowels_ref` and `around` use it,
each bit-identical to before. No patch had worked around the missing
starting shape (the fields here start flat), so that half is new
ground: a string or membrane released from a drawn shape, rather than
struck, is now one line.

## B closed (2026-10-30)

A def that returns an array isn't needed. What is reused is the rule,
not the array, and a def of the index tabulated by A already says it:

```
def reflection(areas, j): if j == 0 then 0 else (areas[j - 1] - areas[j]) / (areas[j - 1] + areas[j])
let r  = array(len(a),  j => reflection(a, j))
let nr = array(len(nA), j => reflection(nA, j))
```

Several arrays filled from shared work (a step) are declared by the
caller and filled with `each`, in place or by a def that takes them by
name, since a def's writes land in the caller's arrays. So defs keep one
shape of result, a number or a pair; B's "only in a let" and its `def
rec` exception never arise.

The rule that a def ends in an expression stays. With no `end` and no
meaning in indentation, the expression is what closes a body, and a bare
expression at the top level is the program's sound. A def that only
fills arrays ends in `0` and is called as `let _ = …`; no patch has one.
