## 1. Text in the language: lyrics and phonemes (low priority)

Roland, 2026-10-12: the singer is a fun experiment, not the language's
focus. Only do this if it falls out cheaply and elegantly; the delay fix,
state arrays and `import` come first.


The singer's lyrics are numeric arrays (phoneme ids per 32nd slot, and a
note per slot) generated by `notes/phon.py` from text like
`DH:1 AX:2 @7 / D:1 IH:4 JH:2 @10`. You can't live-code words: every
lyric change goes through a Python helper.

Wanted: a compile-time string literal that becomes a constant array, e.g.
`let lyr = phonemes("DH:1 AX:2 @7 / ...")` (or a general `"..."` literal
plus a few compile-time string builtins), so the score stays readable and
hot-swappable. `notes/phon.py` is the reference for the format (long stops
hold one closure and release once; voiced ones get the voice-bar id 36).

## 2. `import` / include

Patches are monolithic and copy defs between them: `didge_bore`,
`didge3`, `formant`, `contact`/`bar` (clapsticks), `kres` and the
phoneme tables. `didge_scope.aither` is ~25 KB, mostly shared code.
Wanted: `import "lib/voice.aither"` (defs and constant tables only), so
instruments live in a library and a patch is just the arrangement. Hot
reload should also notice when an imported file changes.

## 3. State migration across different defs (BUGS_AND_ISSUES.md)

A renamed statement inherits a vanished statement's state when only
(typeName, perTypeIdx, size) match, even from a different def. Replacing
`stick` ($x,$dx x3) with `bar` ($bv,$bx x3) copied old displacement into
the new physics; `aither try` showed +24 dBFS. Fix idea: include the
helper/def name (and maybe the $var names) in the fallback key.

## 4. Muted parts still cost full CPU

`mute` zeroes a part's gain but still computes it every sample. The
2026-10-10 crackle was the engine underrunning a 760-line patch with 21
muted parts (fixed by writing a lean patch). Wanted: a muted part (gain 0,
fade done) skips its body, keeping its state frozen, or an explicit
`park` command that does.

## 5. Scope-aware meters and an offline renderer

- `try`, `parts`, `check` count the `scope` and `beam` parts as audio, so
  every real part is flagged QUIET (24-30 dB under the beam). Exclude
  them from the level comparison, or meter them separately.
- There's no `aither render patch secs out.wav`; I built
  `~/aither-tools/towav` on lab (a few lines over `render.nim`). Wanted:
  a proper `render` command, optionally writing all five channels (mix +
  beam X/Y/Z) when the patch has a scope.

## Added 2026-10-12 (from the physical singer)

Found while building a physical singer (a fun side experiment, not the
language's focus), but they help all physical modelling: tubes, strings,
membranes, the didge.

- **`delay()` truncates to whole samples, and a 0-sample delay returns the
  oldest sample in the buffer** (`dsp.nim` nDelay: `int(time * sr)`, read
  before write). Physical models need fractional delays: add linear (or
  allpass) interpolation, and make a 0-sample delay mean "this sample's
  input" or clamp to 1. The 8-region tube was 27% too short until it
  interpolated two taps by hand. The didge's pitch would also get exact.
- **Spatial physics needs code generation.** `tube24` (24 one-sample
  sections, each a forward and a backward wave coupled to its neighbours)
  is 219 generated lines (`gen_tube24.py`), because there are no state
  arrays with neighbour access. Wanted: element-wise state arrays
  (`$f[24]`, `$b[24]`, read last sample's neighbours, write this
  sample's), or a `waveguide(src, areas[], ...)` primitive. Strings,
  membranes and plates would become one-liners too.
- `import` (item 2 above) matters more now: tube24 and the phoneme tables
  belong in a library, not in every patch.
- **`lp1` / `hp1` take a coefficient, not hertz.** `dsp.nim` uses
  `a = cutoff / sr`, so `lp1(x, 4000)` has its -3 dB point near 640 Hz
  (the true one-pole is `a = 1 - exp(-2*pi*fc/sr)`). Either fix the
  formula (and retune patches that lean on today's behaviour, e.g. the
  didge's `lp1(back, 2200)`, really ~350 Hz) or document it loudly. The
  vocal tract now passes 19580 to get a real 4 kHz.

## Added 2026-10-12 (from moving the singer into lib/voice.aither)

- **Every `noise()` is the same noise.** `emitNoise` (codegen.nim) gives
  each call its own pool slot, but every slot starts at 0 and so at the
  same seed (2463534242): all noise sources in a patch play one identical
  sequence. The singer's aspiration, frication and pitch wander are
  perfectly correlated, and so are the didge's breath and anything else
  hissing. Seed each slot from its region offset (or a hash of the call
  site) so they're independent and still deterministic for `render`.
